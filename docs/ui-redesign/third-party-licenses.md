# Third-party design assets

## Be Vietnam Pro

- Source: [google/fonts `ofl/bevietnampro`](https://github.com/google/fonts/tree/main/ofl/bevietnampro)
- License: SIL Open Font License 1.1.
- Local files: `assets/fonts/BeVietnamPro/`.
- The upstream `OFL.txt` and `upstream_info.md` are kept next to the vendored
  font files. The font is bundled locally; the app never fetches it at runtime.

## Phosphor Icons

- Source: [phosphor-icons/homepage](https://github.com/phosphor-icons/homepage)
  and the official Flutter port `phosphor_flutter`.
- License: MIT, copyright Phosphor Icons.
- The dependency is pinned in `pubspec.yaml`; its package license is retained
  by Pub in the resolved dependency cache and is included in the release
  dependency notices.
